# Consent Records Template

> قالب تصميمي يحتاج مراجعة قانونية وربطه بجدول consent records الفعلي قبل الإنتاج.

يجب أن يتضمن سجل الموافقة معرّف المستخدم، الغرض، نص/نسخة الإشعار، locale، timestamp، مصدر الموافقة، version، ووقت السحب إن حدث. تُخزن السجلات بأقل بيانات لازمة، وتُحمى بعزل المستخدم ولا تُسجل tokens أو محتوى البريد.

تُراجع أغراض التسويق والتحليلات وWeb Push منفصلة عن الموافقة الضرورية لتقديم البريد والأمان. يجب أن يكون withdrawal قابلًا للتنفيذ وأن يظهر في audit log المناسب.
