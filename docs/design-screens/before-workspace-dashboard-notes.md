
## Baseline comparison detail

The baseline `/workspace` route exists, but it renders only the earlier Workstream dashboard: a compact search, five metric cards, Smart Inbox, overdue tasks, meetings, and follow-ups. It lacks the v0.8 visible filters, saved-search and customization controls, drafts/needs-reply panels, and six-card overview. Its Sidebar Compose control is not wired from this standalone page, so the baseline Compose capture is taken from `/` where the existing handler is active.
